# TapTaxiBcn

Multilingual taxi booking website for a Barcelona-based driver. Built with Next.js, Tailwind CSS and Motion.

Languages: Spanish, Catalan, English and French. The site detects the browser language on first visit and remembers a manual choice.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customise

Update phone, WhatsApp and email in `src/lib/site.ts`.

Edit translations in `src/i18n/messages.ts`.

Replace placeholder reviews with genuine testimonials before launch.

Quoted fares are estimates in euros. Connect a real booking inbox or messaging workflow before taking live jobs.

## Build

```bash
npm run build
npm start
```
